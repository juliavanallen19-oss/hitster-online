# Hitster Online

A fully browser-based digital version of the physical Hitster music trivia card game. 
Players build a personal timeline of songs sorted by release year, earning cards for 
correct placements and spending tokens on strategic jokers. We built it because we 
looked for a digital version ourselves and no solution with an appealing user interface 
existed yet.

The application supports 2–6 players, runs on any modern device without installation 
or an account, and opens directly in a browser — no server, no backend, no dependencies.

**Live version:** https://juliavanallen19-oss.github.io/hitster-online/ 

## Features

- 200 curated songs spanning 1960–2026
- 4 game modes (Original, Chill, PRO, Quick Fire) — same core logic, different levels 
  of strictness to suit newcomers and competitive players alike
- Token-powered jokers: Skip, Challenge, and Buy Placement
- 30-second iTunes audio previews for Quick Fire mode
- QR codes linking directly to Spotify for all other modes
- Fully responsive — desktop, tablet, and phone
- All sounds synthesised in the browser via the Web Audio API — no audio files needed

## How to Run

Open `index.html` in any modern browser. No installation, no server required.  
Or visit the live version directly: https://juliavanallen19-oss.github.io/hitster-online/
